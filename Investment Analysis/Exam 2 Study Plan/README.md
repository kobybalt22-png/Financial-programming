## How to use each day

1. **Skim the slides listed for that day (10 min).** Just get oriented.
2. **Read the day's notes (15–20 min).** Each one covers what the slides say, plus another way to explain it.
3. **Do the practice problems (20–30 min).** Answers are hidden under **"Show answer"**, so try each problem first.
4. **Write a 3-line recap from memory (5 min).** If you can't write it, re-read that section.
5. **Warm-up (5 min, from Day 2 on).** Redo one problem from the day before.

## Calculator keys reminder (BA II Plus / financial calculator)

| Key | Meaning | Semiannual bond? |
|---|---|---|
| `N` | number of periods | years × 2 |
| `I/Y` | rate **per period** | annual YTM ÷ 2 |
| `PV` | price (enter as **negative**, since you pay it) | — |
| `PMT` | coupon per period | annual coupon ÷ 2 |
| `FV` | face value (usually 1,000), or call/sale price | — |

> The most common mistake on exams is forgetting to halve the rate and double N for semiannual bonds. Also, `I/Y` comes out per period, so multiply by 2 to annualize (BEY).
